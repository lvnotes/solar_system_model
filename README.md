# 🪐 Сонячна система

Інтерактивна 2D-модель Сонячної системи в одному HTML-файлі. Планети рухаються еліптичними орбітами з реальними періодами обертання, а їхні положення відповідають сьогоднішній даті.

## Посилання

https://lvnotes.github.io/solar_system_model/

## Можливості

- Реальні орбіти та швидкості. Еліптичні орбіти за законами Кеплера. Біля Сонця планета рухається швидше, далеко від нього повільніше.
- Два масштаби. «Реальний» зберігає справжні пропорції відстаней, а «стиснутий» робить усі орбіти зручними для перегляду на одному екрані.
- Зум до 20 000×. Масштабування колесом миші, щипком або слайдером, переміщення перетягуванням і режим «Стежити за планетою».
- Реалістичні розміри. У реальному масштабі Сонце, планети та супутники мають справжні радіуси відносно орбіт.
- Супутники. Місяць, Фобос і Деймос, галілеєві супутники Юпітера, Енцелад, Рея, Титан, Титанія, Оберон і Тритон зі справжніми періодами обертання. У реальному масштабі їхні орбіти та розміри теж справжні.
- Сліди планет. Затухаючий слід, довжина якого залежить від періоду обертання.
- Пояс астероїдів. Близько 900 астероїдів із проміжками Кірквуда.
- Керування часом. Пауза та швидкість від 1 до ~2000 днів за секунду.
- Адаптивний інтерфейс. Працює на телефоні та комп’ютері.

## Технології

HTML, CSS і чистий JavaScript (Canvas), без бібліотек.

## Примітки

Орбітальні елементи взяті на епоху J2000, нахили орбіт не враховано (модель плоска). Орбіти супутників і розміри в «стисненому» масштабі схематичні.
